# Agent Framework Runtimes

LocalClaw is framework-agnostic. Every client agent shares the **same persona files**
(`SOUL.md`, `IDENTITY.md`, `AGENTS.md`, `USER.md`, `TOOLS.md`, `MEMORY.md`, `HEARTBEAT.md`)
generated by `onboard.sh`. What changes per framework is the **runtime** that loads them.

`onboard.sh --framework <name>` copies the matching guide below into the agent's
`runtime/SETUP.md`, writes `runtime/system-prompt.md` (all persona files concatenated in
load order), a `runtime/.env.example`, and a `framework.json` manifest.

| `--framework`   | Runtime                         | Guide                    |
|-----------------|---------------------------------|--------------------------|
| `openclaw`      | OpenClaw (+ NemoClaw guardrails) | registered via `openclaw` CLI (default) |
| `hermes`        | Hermes Agent (Nous Research)    | [hermes.md](hermes.md)   |
| `claude-sdk`    | Claude Agent SDK (Anthropic)    | [claude-sdk.md](claude-sdk.md) |
| `openai-agents` | OpenAI Agents SDK               | [openai-agents.md](openai-agents.md) |
| `crewai`        | CrewAI                          | [crewai.md](crewai.md)   |
| `langgraph`     | LangGraph                       | [langgraph.md](langgraph.md) |
| `n8n`           | n8n AI Agent workflows          | [n8n.md](n8n.md)         |
| `custom`        | Bespoke build                   | [custom.md](custom.md)   |

Always confirm current install steps against each framework's official documentation —
these guides capture LocalClaw's conventions, not vendor docs.
